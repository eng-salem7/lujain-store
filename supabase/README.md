# إعداد قاعدة بيانات متجر لجين LUJAIN على Supabase

تم تصميم قاعدة البيانات وفق أعلى المعايير المعمارية لدعم **المتجر الإلكتروني** و**تطبيق العملاء (Flutter)** و**تطبيق ولوحة الإدارة**.

---

## محتويات المجلد

1. `01_schema.sql`: تعريف الهيكل الكامل للجداول، المفاتيح الأساسية والخارجية، القيود، محفزات التحديث، ودوال الحجز الذري للمخزون.
2. `02_rls.sql`: سياسات الأمان على مستوى الصف (Row Level Security) لحماية البيانات بحسب الأدوار والصلاحيات.
3. `03_seed.sql`: البيانات الأولية التجريبية (مناطق الشحن في المحافظات اليمنية، العملة بالريال اليمني YER، حسابات الصندوق والمحافظ الإلكترونية: الكريمي، فلوسك، جوالي، ون كاش، التصنيفات والمنتجات والألوان والمقاسات والمخزون، كوبونات الخصم، والطلبات التجريبية).
4. `full_setup.sql`: ملف التثبيت الموحد (يجمع الهيكل + الأمان + البيانات الأولية) لتشغيله بنقرة واحدة.

---

## خطوات التثبيت في Supabase خطوة بخطوة

1. سجّل الدخول إلى [لوحة تحكم Supabase](https://supabase.com/dashboard).
2. أنشئ مشروعاً جديداً باسم: **`lujain-store`**.
3. اختر منطقة خادم قريبة (مثل `Frankfurt` أو `Bahrain`).
4. بعد إنشاء المشروع، توجّه إلى القائمة الجانبية واختر **SQL Editor**.
5. انقر على **New Query**.
6. انسخ كامل محتوى الملف `supabase/full_setup.sql` والصقه في المحرر.
7. اضغط على الزر الأخضر **Run**.
8. ستظهر رسالة `Success: Success. No rows returned`.

## إعداد وسائط التخزين (Storage Buckets)

من لوحة Supabase، توجه إلى قسم **Storage** وأنشئ الـ Buckets التالية:
- `product-images`: (Public: نعم) لتخزين صور المنتجات والأقسام.
- `payment-proofs`: لتخزين صور إشعارات التحويل وحوالات الكريمي وفلوسك.
- `expense-receipts`: لتخزين صور فواتير المصروفات وسندات التوريد.

---

## ربط المشروع مع المتجر والموقع والتطبيق

توجه في لوحة تحكم Supabase إلى:
**Project Settings** ➔ **API**

انسخ القيمتين:
- **Project URL**: `https://<your-project-id>.supabase.co`
- **Anon Public API Key**: `eyJhbGciOi...`

وضعها في ملفات البيئة `.env`:
- في مجلد الويب: `web/.env.local`
- في مجلد تطبيق الهاتف: `mobile/lib/core/supabase_config.dart`
