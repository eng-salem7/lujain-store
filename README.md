# متجر لُجين LUJAIN للأزياء النسائية
> **«أناقتكِ تبدأ من هنا»**  
> المنصة المتكاملة لتجارة الأزياء النسائية الراقية: متجر إلكتروني • تطبيق الإدارة • تطبيق الهاتف (Flutter) • قاعدة بيانات موحدة (Supabase).

---

## 🌟 نبذة عن المشروع

مشروع **لجين LUJAIN** هو نظام تجارة إلكترونية متكامل مخصص للملابس والأزياء النسائية (فساتين سهرة، جلابيات مطرزة، أطقم رسمية وكاجوال، بلايز وقمصان، تنانير وبناطيل، شيل وإكسسوارات).

تم بناء المشروع بقنوات موحدة ترتبط بقاعدة بيانات مركزية آمنة على **Supabase PostgreSQL**، مع دعم العملة الرسمية **الريال اليمني (YER)**، ومناطق الشحن والتوصيل لكافة المحافظات اليمنية، والمحافظ الإلكترونية الشائعة (الكريمي حاسب، فلوسك، جوالي، ون كاش) بالإضافة إلى الدفع عند الاستلام.

## 🚀 تشغيل متجر الويب ولوحة الإدارة (Web & Admin)

المتجر ولوحة الإدارة مبنيان بـ **Next.js 14+** و **Tailwind CSS** و **TypeScript**:

1. توجه إلى مجلد الويب:
   ```bash
   cd web
   ```
2. تثبيت الحزم والمكتبات:
   ```bash
   npm install
   ```
3. تشغيل خادم التطوير المحلي:
   ```bash
   npm run dev
   ```
4. افتح المتصفح على:
   - المتجر الإلكتروني للعميلات: `http://localhost:3000`
   - تتبع الطلب: `http://localhost:3000/track-order`
   - لوحة تحكم الإدارة: `http://localhost:3000/admin`

## 📱 تشغيل تطبيق الهاتف (Flutter Mobile App)

تطبيق الهاتف يدعم كلاً من نظامي **Android** و **iOS**:

1. توجه إلى مجلد التطبيق:
   ```bash
   cd mobile
   ```
2. جلب حزم فلاتر:
   ```bash
   flutter pub get
   ```
3. تشغيل التطبيق على المحاكي أو جهاز متصل:
   ```bash
   flutter run
   ```

## 🗄️ ربط قاعدة البيانات (Supabase PostgreSQL)

راجع الدليل التفصيلي في [SETUP_DATABASE.md](./SETUP_DATABASE.md):
1. أنشئ مشروعاً جديداً على Supabase باسم: **`lujain-store`**.
2. افتح **SQL Editor** والصق محتويات الملف الموحد [`supabase/full_setup.sql`](./supabase/full_setup.sql) واضغط **Run**.
3. انسخ `Project URL` و `anon key` وضعهما في:
   - `web/.env.local`
   - `mobile/lib/core/supabase_config.dart`

## 🛡️ معايير الأمان وقواعد العمل المعتمدة

- **لقطات ثابتة للأسعار (Price Snapshots)**: تُحفظ أسعار وتكاليف وبيانات المنتجات والعناوين كلحظة تاريخية داخل الطلب لمنع تأثر الطلبات السابقة بأي تعديل مستقبلي للمنتج.
- **حجز المخزون الآمن**: لا يمكن بيع آخر قطعة مرتين؛ النظام يحجز الكميات في قاعدة البيانات عبر دوال ذرية (Atomic Functions).
- **سياسات RLS**: حماية بيانات العملاء والمبيعات والأرباح والتكاليف وفق صلاحيات الأدوار المعتمدة.
- **سجل تدقيق غير قابل للتعديل**: تتبع حركات المخزون والمصروفات بدقة محاسبية كاملة.
